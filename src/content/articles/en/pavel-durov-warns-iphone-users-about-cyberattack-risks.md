The warning is primarily aimed at iPhone owners who have not updated their operating systems for some time.
**What should users do?**
To reduce cybersecurity risks, iPhone users are advised to:
Install the latest available version of iOS;
Enable automatic software updates;
Avoid opening suspicious or unfamiliar links;
Regularly check for security updates for their operating system and apps.
Using an outdated operating system can leave devices vulnerable to known security flaws. Keeping software up to date is therefore an important security measure.
